# My Portfolio Template

A React + Tailwind CSS + Framer Motion portfolio with animated background, curtain-style loading screen, custom cursor, magnetic buttons, 3D tilt project cards, and scroll-triggered animations.

## Setup

1. Install [Node.js](https://nodejs.org) if you don't have it already.
2. Open this folder in a terminal.
3. Install dependencies:
   ```
   npm install
   ```
4. Start the dev server:
   ```
   npm run dev
   ```
5. Open the link shown in the terminal (usually `http://localhost:5173`) in your browser.

## Customize it

- **Your name / role / bio**: edit the text directly inside `src/App.jsx`.
- **Your photo/video**: add your files to `src/assets/`, then uncomment the `import` lines at the top of `src/App.jsx` and swap in the `<img>` / `<video>` tags where the placeholders are (marked with comments).
- **Skills**: edit the arrays inside the Skills section (e.g. `["JavaScript", "React", ...]`).
- **Projects**: edit the Projects section — update titles, descriptions, and links.
- **Contact email / social links**: replace `youremail@example.com` and the `href="#"` links with your real ones.
- **Colors**: this template uses Tailwind's `red` and `blue` color classes throughout — find & replace with any Tailwind color name (e.g. `emerald`, `purple`) to re-theme it.
- **Resume**: put a `resume.pdf` file in the `public/` folder so the Download Resume button works.

## Tech used

- React + Vite
- Tailwind CSS
- Framer Motion (animations)
- react-type-animation (typing effect)

Enjoy building your own version! 🚀
